# 知人镜

移动优先的静态 Web 产品：帮助用户 **避免被欺**、**理解关系**、**以慈悲抱持他人**。  
看见是为了抱持，不是为了操控。

## 如何打开

```bash
cd /workspace/shiren-mirror
python3 -m http.server 8891
```

浏览器访问：<http://127.0.0.1:8891/>

无需构建、无框架、无外部字体/API Key。纯 HTML + CSS + JS，可离线使用智能识人启发式引擎。

## 页面

| 文件 | 说明 |
|------|------|
| `index.html` | 首页：产品意图与入口 |
| `kb.html` | 知识库卡片列表（可搜索） |
| `module.html?id=…` | 模块详情（亦可 `kb.html#id` 跳转） |
| `ask.html` | 智能识人：伦理门禁 + 多透镜合成 |

## 产品原则

1. **防欺自保**：红旗/绿旗、一致性、边界——保护自己 ≠ 审判他人。  
2. **理解关系**：假设 2–4 个、情境验证、概率语言，不贴永久标签。  
3. **抱持伦理**：正知正见正念；帮助有边界；危机时指向专业支持。  
4. **明确拒绝**：操控、欺骗、套路、报复、跟踪、PUA、诈骗等意图。  

## 技术说明

- 数据：`js/kb.js`（19 个模块）  
- 伦理：`js/ethics.js`（拒绝 / 软提示 / 允许）  
- 引擎：`js/engine.js`（关键词评分 + 模板合成；文件内注释标明 AI Gateway 接入点）  
- 样式：`css/site.css`（墨色底、柔金点缀、中文衬线标题栈）
